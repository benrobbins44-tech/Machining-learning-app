# Shop Academy V2 — iPhone PWA

A mobile-first progressive web app for machining, welding and fabrication training.

## iPhone
The app must be hosted at an HTTPS web address for Safari's "Add to Home Screen" web-app installation flow.

1. Open the site in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Enable Open as Web App if shown.
5. Tap Add.

The service worker caches the core app for offline use after the first visit.

## Included
- 44 structured modules across machining, welding and fabrication
- Lesson content and knowledge checks
- Local progress and XP
- Shop equipment profile
- RPM, tap-drill and unit calculators
- Hands-on project challenges
- Responsive iPhone-first interface
- PWA manifest/service worker
